# Pictures

Two candidates for each slot, `-a` and `-b`, made with a local image
generator (FLUX.1 Schnell, run locally). The `.json` beside each holds
the prompt, seed and settings, so any of them can be made again.

The `-a` picture is the one copied into `site/img/` as a placeholder.
**A maintainer picks the keeper for each slot.** To switch one, copy the `-b`
file over the matching file in `site/img/` (for example
`art/hero-b.jpg` to `site/img/hero.jpg`).

Rules for new pictures are in `DESIGN.md`: one warm side light, dark
background, no people, and no words, labels, logos or numbers.
