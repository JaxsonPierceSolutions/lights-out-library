About this library

What it is, what is on this computer, how to add more, and who the books belong to.

What it is

A set of reference books and a search page that run on this computer with no internet. The books are downloaded ahead of time from download.kiwix.org, the official home of the Kiwix offline library. After that, nothing here needs or uses a network. The pages can only be opened from this computer.

Every book, its size and its license

This project ships none of these books. Each person downloads their own copy, and each book stays under its own license. "Not confirmed" means we could not find a clear statement, so do not copy or sell that book.

Ask (optional AI)

Ask is off unless you turn it on. It uses a small AI model that runs on this computer through a free program called Ollama, which you install yourself. It reads pages from the library and answers from them. It can be wrong, and it is slow on a laptop without a graphics card.

To turn it on: install Ollama, run ollama pull for one model above and for , then copy config.example.json to config.json and set ask.enabled to true and ask.model to the model's name.

Fonts and software

Text is set in Geist (SIL Open Font License 1.1). Books are served by kiwix-serve (GPL 3.0 or later), downloaded by the fetch script. The pictures were made for this project.
