# 0003: This project is open source

**Date:** 2026-11-10 · **Decided by:** Jaxson Pierce Solutions

Lights Out Library is public and open source under the MIT license, so
friends, family and strangers can download it, change it and have it
ready before they need it. The books keep their own licenses
(`docs/licenses.md`); the project never ships books, music or films.

Done before it went public:

- [x] MIT license for the code, pages, docs and pictures.
- [x] Checks that live in this repo (`.github/workflows/ci.yml`): tests on
      Windows, Linux and macOS, the browser test, and the shell scripts.
- [x] A contributor guide for outside contributors, and a security note.
- [x] A plain disclaimer in the README: not medical advice, no warranty.
- [x] The repo was read for anything personal. It starts from a single
      clean commit, so no earlier draft is in its history.

People asked to add their own files, music included, and make it work
better for themselves: that is the Your own files page and add-on layers.
